# TrustFL-SIS Workshop Website

Static one-page website for **TrustFL-SIS: Trustworthy Federated Learning for Smart Industrial Systems**, workshop at IEEE ICDM 2026.

## Files

- `index.html` — one-page website
- `styles.css` — responsive styling
- `script.js` — mobile menu
- `logo.svg` — workshop logo
- `favicon.svg` — browser icon

## Deploy on GitHub Pages

1. Upload all files to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Save and wait for GitHub Pages to publish the site.

The site will normally be available at:

`https://USERNAME.github.io/REPOSITORY-NAME/`

For example, if the repository is `MODAL-UNINA/TrustFL-SIS`, the URL will be:

`https://modal-unina.github.io/TrustFL-SIS/`

- `icdm2026-logo.png` — the exact ICDM 2026 logo image provided by the user
